## Use

`sphinx file <subcommand>`

## Description

File operations.

## Flags 

No flags.

### Subcommands

- [`sphinx file add`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/file/subcommands/add.md): Add files to the database.
- [`sphinx file show`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/file/subcommands/show.md): Print file content to the standard output.
- [`sphinx file list`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/file/subcommands/list.md): List files.
- [`sphinx file move`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/file/subcommands/move.md): Rename/move a file.
- [`sphinx file del`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/file/subcommands/del.md): Remove files from the database.
- [`sphinx file touch`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/file/subcommands/touch.md): Create one, multiple or all the files in the database. In case a path is passed, sphinx will create any missing folders for you.
