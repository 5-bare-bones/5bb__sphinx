## Use

`sphinx entry {subcommand}`


## Description

Entry operations.

## Flags 

No flags.

### Subcommands

- [`sphinx entry add`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/entry/subcommands/add.md): Add entry to the vault.
- [`sphinx entry list`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/entry/subcommands/list.md): List entry.
- [`sphinx entry move`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/entry/subcommands/move.md): Rename/move a file.
- [`sphinx entry del`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/entry/subcommands/del.md): Remove entry from the vault
- [`sphinx entry move`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/entry/subcommands/move.md): Move an entry to another place in the vault.
- [`sphinx entry rotate`](https://github.com/5-bare-bones/5bb__sphinx/tree/master/docs/commands/entry/subcommands/rotate.md): Update a password automatically.
