## Use

`sphinx config`

*Aliases*: cfg.

## Description

Configuration file operations. This command will print the configuration file on the terminal.

### Subcommands

- `sphinx config argon2`: Show argon2 parameters being used.
- `sphinx config create`: Create a configuration file.
- `sphinx config edit`: Edit the current configuration file.

## Flags 

No flags.

### Examples

Read configuration file:
```
sphinx config
```
