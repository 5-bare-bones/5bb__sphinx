## Use

`sphinx vault stats`

## Description

Show vault statistics.

## Flags 

|  Name     |     Type      |    Default    |              Description                |
|-----------|---------------|---------------|-----------------------------------------|
| json      | bool          | false         | Output statistics in JSON format        |

### Examples

Show statistics:
```
sphinx vault stats
```

Show statistics in JSON format:
```
sphinx vault stats --json
```
